# Your Delivery Code

Every order gets a **6-digit delivery code**. It is proof that you actually received your item, and it is the single most important thing you hold as a buyer.

## Why it exists

Without it, a vendor could mark an order delivered on their word alone, and money would leave escrow whether or not anything reached you. Proving you never received something is close to impossible.

The code fixes that. It only works if you hand it over, so:

- A vendor cannot claim a delivery that never happened
- You cannot receive an item and then claim it never arrived

It protects both sides, which is why it is worth using properly.

## Where to find it

Open the order under **Orders**. Your code appears as soon as the vendor marks the item **Shipped**, and stays visible until delivery is confirmed.

Before that — while the order is still Order Placed or Processing — the order page tells you the code will appear once the item is on its way.

## How to use it

<Note type="warning">
  Give the code **only after** the item is in your hands and you have looked at
  it. Once the code is entered, delivery is confirmed and the vendor is paid.
</Note>

When the item arrives:

1. Take the item and check it is what you ordered
2. Read the 6 digits out to whoever delivered it, or let them type it in front of you
3. Delivery is confirmed immediately and your order moves to **Delivered**

The person delivering opens a link that shows only what they need — the first name to hand over to, and a box for the code. It never shows your address, phone number, surname, or what you paid.

## Rules of thumb

<Warning>
  Never send your delivery code in chat, over the phone before arrival, or to
  anyone who has not physically handed you the item. Anyone with the code can
  confirm a delivery that did not happen.
</Warning>

- **Do not** give the code to "confirm your order" or "verify your account" — no one at Soraxi will ever ask you for it
- **Do not** send it ahead so the rider "can save time"
- **Do** check the item first, even briefly
- **Do** keep the code until delivery actually happens

## If something goes wrong

**The item is wrong or damaged.** Do not give the code. Message the vendor immediately and, if it is not resolved, raise a dispute. See [Opening a Dispute](/docs/protection/opening-a-dispute).

**The rider cannot open the link.** They can call the vendor and read the code over the phone instead. It is the same code and the same confirmation — you still control when it is released.

**The code was entered incorrectly several times.** The link stops working, to protect you. Delivery can still be confirmed another way: mark the order received in the app once you have the item.

**You already gave the code and then found a problem.** You can still raise a dispute after delivery, as long as you do it before the order settles. Do it promptly.

## FAQs

**Q: I lost the code.**
A: It is on your order page for as long as the order is awaiting delivery. It does not change.

**Q: Someone else is collecting for me.**
A: Give them the code only if you trust them to check the item first. Once entered, the delivery is confirmed in your name.

**Q: Do I still need to confirm in the app after giving the code?**
A: No. The code confirms it.

**Q: Nobody asked me for a code.**
A: Some vendors confirm delivery a different way. If your order shows Delivered and you have your item, nothing is wrong. If it shows Delivered and you do **not** have your item, raise a dispute straight away.
