# Proof of Delivery

When you mark an order **Shipped**, Soraxi issues the buyer a 6-digit delivery code and creates a confirmation link for whoever is delivering.

Getting that code entered at handover is the best thing you can do for your own protection.

## Why it matters to you

Confirming delivery with the buyer's code creates a record that the buyer was present and released it. If that buyer later claims the item never arrived, you have something concrete standing behind you.

<Note type="success">
  The code is not paperwork. It is the difference between "I delivered it" and a
  record showing the buyer confirmed the handover — and that difference decides
  disputes.
</Note>

It also pays you immediately: entering the code confirms delivery and releases your money from escrow on the spot, rather than waiting.

## How to confirm a delivery

### The rider enters the code

When you mark the order Shipped, you get a confirmation link. Send it to whoever is delivering.

At handover, they open the link, enter their name and the 6 digits the buyer gives them, and the delivery is confirmed instantly. The link shows them nothing but the first name to hand over to and a box for the code — no address, no phone number, no order value.

### You enter the code yourself

If the rider has no smartphone or the link will not load, they call you and read out the code the buyer gave them. You enter it from your store.

This is the same code and the same confirmation — only the keyboard differs.

### The buyer confirms in their app

Some buyers simply mark the order received themselves. Nothing further is needed from you.

## When you cannot get a code

Sometimes the code is genuinely unavailable — the buyer cannot find it, or the link has stopped working after too many wrong entries. You can still mark the order delivered.

<Warning>
  Marking an order delivered without a code is supported, but it is your word on
  its own. If the buyer disputes it, you have nothing to point to. Use it as a
  last resort, and get the buyer to confirm in their app instead wherever
  possible.
</Warning>

If the code will not work, the cleanest route is to ask the buyer to confirm delivery in their own app while you are standing there. That is a first-party record and takes them ten seconds.

## Practical advice

- **Send the confirmation link to the rider before they set off**, not while they are at the door
- **Ask for the code at handover**, after the buyer has the item — buyers are told not to give it early, and pressing for it beforehand looks exactly like the behaviour we warn them about
- **Do not ask a buyer to send the code in chat.** Buyers are told never to do this, and asking damages their trust in you
- **If a buyer refuses the code** because something is wrong with the item, sort the problem out. That refusal is the system working — it is your chance to fix it before it becomes a dispute

<Note type="warning">
  Never mark an order delivered before it has arrived, for any reason. It is
  treated as a serious breach and it is exactly what the code exists to detect.
</Note>

## After confirmation

Once delivery is confirmed:

- The order shows **Delivered**
- Your payment is released from escrow
- The buyer can review the product
- The buyer can still raise a dispute for a short window — see [When a Buyer Disputes an Order](/docs/fulfilment/vendor-disputes)

## If nobody confirms

If neither the code nor the buyer confirms, Soraxi confirms the delivery automatically **3 days** after the item goes out for delivery, and you are paid then.

That works, but it costs you three days and leaves no evidence of handover. Getting the code is faster and safer.

## FAQs

**Q: Does the code expire?**
A: The rider's confirmation link is usable for a limited period after despatch. The code itself stays on the buyer's order until delivery is confirmed.

**Q: The rider entered the wrong code several times.**
A: The link stops working, to protect the buyer. Ask the buyer to confirm in their app, or enter the correct code yourself.

**Q: Can I see the buyer's code?**
A: No. It is the buyer's to give — that is what makes it evidence.

**Q: I deliver personally. Do I still need it?**
A: Yes, and it is easy: ask for the code at the door and enter it yourself.

**Q: The buyer gave me the code but the order still shows Shipped.**
A: The code must be entered — by the rider on the link, or by you. Handing it over does not confirm anything on its own.
